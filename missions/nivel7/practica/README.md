Misión: Crear un script automatizado

Tu tarea es crear un script llamado "reporte.sh" que:
1. Muestre la fecha actual
2. Liste todos los archivos .txt en este directorio
3. Cuente cuántos archivos .txt hay
4. Guarde el resultado en un archivo llamado "resultado.txt"

Pistas:
- Usa 'date' para mostrar la fecha
- Usa 'ls *.txt' para listar archivos
- Usa 'ls *.txt | wc -l' para contar
- Usa '>' para redirigir salida a un archivo

¡Buena suerte, Agente!
